# مكتبة ديوان دان — الإصدار 2.0

واجهة مكتبة رقمية عربية احترافية، متجاوبة، وتعمل كنسخة static قابلة للنشر على GitHub Pages.

## المزايا
- تصميم RTL حديث للهاتف والكمبيوتر.
- لوحة رئيسية وإحصائيات.
- إضافة وتعديل وحذف الكتب.
- رفع PDF وقراءته داخل المتصفح.
- رفع غلاف للكتاب.
- البحث في العنوان والمؤلف والوصف.
- ترتيب الكتب.
- المؤلفون والتصنيفات.
- المفضلة.
- الوضع الليلي.
- تصدير واستيراد بيانات المكتبة JSON.
- تبدأ المكتبة فارغة بدون كتب تجريبية.

> ملاحظة: التخزين محلي على الجهاز عبر localStorage. رفع الكتب إلى مكتبة مشتركة على الإنترنت يحتاج لاحقاً إلى قاعدة بيانات/تخزين سحابي.
